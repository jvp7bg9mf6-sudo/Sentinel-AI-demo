# Sentinel AI: online demo

The demo interface of Sentinel AI, a Grade 12 science fair project: a defensive tool that reads source code and points out security weaknesses, with AI output always shown as an unverified hypothesis.

- All systems, findings and AI results on the demo pages are **simulated**.
- The Research page shows real tuning results on the public OWASP BenchmarkPython practice code, not the final test.
- Code samples on the Demo page come from OWASP Juice Shop, © 2014–2026 Bjoern Kimminich & the OWASP Juice Shop contributors, MIT licence.

This repository only holds the built website. The project's source code is kept elsewhere.
